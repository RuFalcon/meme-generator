# Генератор Мемов

Интерактивное веб-приложение для создания мемов, построенное на React и Vite.

## Возможности

- Загрузка изображений для создания мемов
- Добавление текста сверху и снизу изображения
- Предварительный просмотр мема в реальном времени

## Технологии

- React 18
- Vite
- HTML5 Canvas для рендеринга мемов
- Modern CSS

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/RuFalcon/meme-generator.git
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект локально:
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

## Сборка для продакшена

Для создания продакшен-версии выполните:

```bash
npm run build
```

Готовая сборка будет находиться в директории `dist`.
